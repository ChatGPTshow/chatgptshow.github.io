海外账号升级业务：chatshare.uno 质保 30 天不掉订阅，掉订阅，按天退差价

今天 OpenAI 开发者大会讲的东西很多，模型、套餐、代理和协作入口几乎都碰了一遍。

逐项复盘没有必要，太多人说了。这篇只挑和大多数人“能不能用、要不要加钱”直接相关的部分：GPT-6.1 Sol、套餐、Dots，以及 Codex Cloud 和 ChatGPT Space。

最容易被说乱的，是 GPT-6.1 Sol 这个新模型到底更新了什么，新 Pro $200 为什么从 20x 变成 10x，Dots 又是谁先能用。

一个月连发三版模型，差别在哪

这波不只发了一个 GPT-6.1 Sol。OpenAI 在 26 天内连续推了三版关键模型：9 月 3 日的 GPT-6 Astra、9 月 22 日的 GPT-6 Sol，以及 9 月 29 日的 GPT-6.1 Sol。 它们不是同一模型换名字，而是一条从旗舰能力、到降低成本、再到能力追上的演进线。

先把定位记成一句话：Astra 是“最强”，GPT-6 Sol 是“够强且便宜”，GPT-6.1 Sol 是“价格没上去，但更接近 Astra”。

与gpt-6 sol同期上线的是claude opus 5.5，在对比之下， claude opus5.5完胜gpt-6 sol，GPT 6.1 sol更像是临时打了补丁，看来claude给gpt的压力还是挺大的，也应了这张图。

OpenAI 自己把 GPT-6.1 定义为 GPT-6 系列最新模型家族，并在对比中写明，GPT-6.1 Sol 在多项安全与能力评测上高于 GPT-6 Sol；它同时被定位为接近 Astra 的复杂任务模型。

对大多数人来说，真正的使用差别在于：任务极难、失败成本高时选 Astra；需要高频跑代码和代理任务时，先用 GPT-6 Sol 或 GPT-6.1 Sol；同样的复杂任务，6.1 Sol 更值得优先比较。

API 也能调用 Sol，但 API 账单和 ChatGPT 订阅额度是两套系统。官方当前 API 标价是每百万输入 Token 2 美元、输出 Token 10 美元；别用 API 单价去反推 Plus 或 Pro 的可用次数。

选套餐前，先看你在哪个入口工作

ChatGPT 的订阅不只是聊天窗口的会员。对需要开发和代理能力的人，真正要看的是 Work、Codex、本地任务和云端任务能否满足你的工作量。

Plus 与 Standard Business 的 Sol 参考区间是每 5 小时 15 到 160 条；

云端任务会消耗得更快，本地消息和云端聊天也会共用同一份套餐可用额度，部分套餐还可能有周度限制。

Plus 的公开价是每月 20 美元。Pro 当前分为 100、200 和 500 美元每月三个档位；对于个人高频用户，先把 100 或 200 美元档与自己的实际任务量对照，通常比直接冲 500 美元更理性。

新订 Pro $200 是 10x，存量 20x 要分开看

本次开发者大会推出了Pro $500 套餐订阅，恢复了Pro $200 套餐订阅

不过重点不在Pro $500 ，而是 Pro $200 的计算方式变了。codex负责人Tibo 在 DevDay 当天公开说明，新的相对梯度调整为 Plus 1x、Pro $100 5x、Pro $200 10x、Pro $500 25x，同时重新开放 Pro $200 订阅。

以后不能说 20x了，得说200刀了

同样是 200 美元，存量 20x 在过渡期内的相对额度是新订 10x 的两倍。按 Plus 1x 的价格基线算，新订 Pro $200 相当于每个 1x 花 20 美元；存量 20x 则是每个 1x 花 10 美元。旧 20x 的价值确实在相对上升。

但这里必须把边界讲清。Tibo 的原话是存量用户会“保留一段时间”20x，并得到大量额外 credits；

目前没有公开截止日期，也没有承诺多月预付就能永久锁住 20x。ChatGPT 的订阅规则本身也不支持年付或多月预付。

所以，存量 20x 用户真正该做的是：不要让当前订阅断掉，提前安排下一期续费，避免取消、降级或续费失败。 这不是承诺未来永久保留 20x，而是在官方还未公布过渡终点前，尽量保持现有资格连续。

另外，官方当前写的是：500 美元每月档位提供 GPT-6 Astra Ultrafast。 它的意义是把最强模型放进更低延迟的工作流，适合任务很急、又确实依赖 Astra 的用户。

但 Ultrafast 也不是“无限又白送”。官方说明里，Fast 模式会按 2.5 倍消耗订阅内可用额度；Astra Ultrafast 则按 8 倍消耗订阅可用额度、按 6 倍消耗已购买或企业 credits。这些倍率描述的是额度消耗，并不是承诺响应速度一定快几倍。

换句话说，500 美元档该服务的是“我每天都要用 Astra 处理很重且很赶的任务”。如果你只是想在 Codex 里稳定使用 Sol，优先看自己会不会真的撞上 Plus 或较低 Pro 档的上限，而不是被“Ultrafast”三个字推着升级。

还有一个更省钱的中间方案：Plus 和 Pro 用户在用量打满后，可以购买额外 credits；这比为了少量峰值任务长期升档更合适。它同样不等于给所有模型永久解锁无限额度。

Codex Cloud 负责跑，ChatGPT Space 负责收

Codex Cloud 是 OpenAI 托管的远程执行环境。 你把代码仓库接进去、配置好环境后，可以把任务交给 Codex 在隔离的云端环境里跑，自己先去做别的事；也可以同时开多个任务，等它们给出可审查的 diff 或 PR。官方说明open in new window 把它定位为并行处理较长代码任务的入口。

它和本地 Codex 的区别不只在“能不能开浏览器”。Cloud 会根据你选定的分支或提交创建容器、执行 setup，并按设置处理网络访问。仓库权限、环境变量和互联网访问也是独立配置的；工作区给了 Cloud 权限，不代表它可以越过 GitHub 或 GitLab 原本的仓库权限。云端环境文档open in new window 说得很清楚。

对套餐判断来说，Cloud 的意义是：如果你的任务经常要后台跑很久，或者同时让 Codex 处理多个项目，额度消耗会比本地问几句代码快得多。此时再比较 Plus、Pro 和 credits，才有实际依据。

而 ChatGPT Space 不是一个新的模型，也不是把聊天记录共享出去。它把页面、文件和协作产物放到同一个空间里；一个 space 可以按项目或团队分组，里面的页面可由人和 ChatGPT 一起编辑，再邀请其他人协作。 官方概览open in new window 也把表格、演示文稿、网站、和文件放在同一套内容体系里。

它适合把“聊天里讨论过，但散在各处”的需求、方案、资料和交付物沉下来。需要注意的是，关联进来的文件仍沿用原本权限；但你把内容复制或总结到某个页面后，能访问该页面的人就能看到这部分内容。对团队来说，这比模型名称更值得在意。

Dots 到底先开放给谁

Dots 是另一条产品线。它是由 GPT-6 Astra 驱动、带独立云端电脑的常驻代理，可以长期接任务、操作网页或应用；

简单来说就是：OpenAI 给它配了一台云电脑和浏览器。接上你授权的应用以后，它可以记住你在ChatGPT里的上下文，接入插件，持续跟进任务，你关掉聊天窗口也不用一直盯着，也是走的个人AI Agent的路子。

好家伙，这不就是Grok bot、Muse吗？

另外，有个特别搞笑的是：

OpenAI 刚刚宣布了 Dots，马斯克的SpaceXAI 就买下了 dot.com 这个域名了，直接跳转到 Grok Bot 官网去了，真的太搞笑了哈哈哈

言归正传，按照 OpenAI 当前的 Dots 上手说明open in new window，首批范围是：

  • Pro 用户，但欧洲经济区、瑞士和英国暂不在这一批范围内；

  • Business Premium 用户，覆盖 ChatGPT 已支持的地区；

  • Enterprise 用户，以 beta 形式提供，且必须由工作区管理员开启。

Free、Go、Plus 和 Standard Business 不在这份首批开放名单里。当前官方没有把它们列为可用范围，之后是否开放还是另一回事。

还有三个实际细节：

第一，Dots 是渐进推送，符合条件也可能要等数天。

第二，Enterprise 默认关闭，管理员不开权限，成员看不到。

第三，创建 Dot 目前要用桌面版 App 或桌面网页；手机端可以在已创建后继续沟通，但不能新建。

官方还写明，首月内，符合条件的 Pro、Business 和 Enterprise 用户使用 Dots 暂不计入各自的套餐可用额度；之后的计费或额度规则会再公布。这个阶段最值得关注的不是“它是不是免费”，而是它能否替代你原来反复盯着的浏览器和云端执行任务。
